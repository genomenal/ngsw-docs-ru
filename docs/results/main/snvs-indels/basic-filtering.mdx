## Основные параметры фильтрации {#basic-filtering-columns}

:::caution На заметку
На [странице "Настройки пользователя"](/settings/profile#basic-mode-filters)
можно поменять выбор основных параметров фильтрации. Далее подробно рассказано о тех параметрах,
которые добавлены в настройках по умолчанию.
:::

:::note На заметку
Фильтрация таблицы сохраняется при выходе со страницы SNV Viewer.
:::

### 1. Тип мутации {#origin}

Фильтр вариантов по типу мутации: соматическая (Somatic) или герминальная (Germline).

:::note На заметку
Параметр фильтрации "Тип мутации" не отображается в базовом режиме поиска в
[SNV Viewer с герминальными мутациями](/results/main/snvs-indels/variant-viewer).
:::

Как здесь, так и во всех последующих случаях, <b><i>алгоритм фильтрации</i></b> один:
- Нажмите на поле фильтрации;
- Из появившегося списка выберите нужную опцию фильтрации либо введите интересующую вас опцию в поле
поиска и выберите из найденных.

Готово! Фильтр применен. То, какой выбран фильтр, можно увидеть в окошке (в данном случае выбран тип мутации
"Somatic"):

<p align="center">
<img src={require('/img/vv/set_option.png').default} width="150"/>
</p>

### 2. Панель генов {#gene-panel}

Фильтр вариантов по локализации в определенных генах из панели.
Вы можете добавить панель генов <a href="/settings/gene-panels">на странице "Панели генов"</a>
или импортировать панель из библиотеки самых распространенных клинических панелей. Для импорта
нажмите на "<i>Импорт из библиотеки</i>":

<p align="center">
<img src={require('/img/vv/gene_panel.png').default} width="300"/>
</p>

В открывшейся форме выберите нужные панели, отметив их галочками:

<p align="center">
<img src={require('/img/gene_panels/checked_panels.png').default} width="600"/>
</p>

и нажмите на <img src={require('/img/gene_panels/import_btn.png').default} width="150"/>, чтобы добавить панель.

### 4. Онтология {#hpo}

Фильтр вариантов по локализации в генах, ассоциированных с терминами из онтологий фенотипических аномалий
и заболеваний человека - [Human Phenotype Ontology (HPO)](https://www.ebi.ac.uk/ols/ontologies/hp)
и [Mondo Disease Ontology (Mondo)](https://mondo.monarchinitiative.org/). Нажмите на поле
фильтрации по онтологии. В открывшейся форме поиска в выпадающем списке представлены основные фенотипические группы:

<p align="center">
<img src={require('/img/vv/hpo_search.png').default} width="800"/>
</p>

**Способы поиска и выбора фенотипа или заболевания для фильтрации:**
- **Поиск непосредственно в выпадающем списке.** С фенотипическими группами можно
взаимодействовать с помощью кнопок <img src={require('/img/vv/show.png').default} height="15"/> и <img src={require('/img/vv/hide.png').default} height="10"/> для
раскрытия и сворачивания списка терминов группы, соответственно:

<p align="center">
<img src={require('/img/vv/list_of_phenotypes.png').default} width="270"/>
</p>

Кроме того, фенотип или заболевание можно найти с помощью поиска:
- по названию (полному или частичному);
- по идентификатору HPO (например, "HP:0009733" или "0009733");
- по идентификатору Mondo (например, "MONDO:0009733" или "0009733").

Например, при поиске по запросу “glioma” отображаются несколько соответствующих терминов:

<p align="center">
<img src={require('/img/vv/glioma_search.png').default} width="800"/>
</p>

Чтобы выбрать термин для фильтрации, нажмите на соответствующую строку. Для фильтрации можно использовать
как целую фенотипическую группу, так и отдельный фенотип. После выбора фенотипа (например, "Glioma")
отображается его карточка:

<p align="center">
<img src={require('/img/vv/glioma_page.png').default} width="800"/>
</p>

В левой части карточки отображается полное название фенотипа или заболевания со ссылкой на соответствующую
страницу в онтологии HPO или Mondo (на базе консорциума [Monarch Initiative](https://monarchinitiative.org/)),
а также вся доступная информация из выбранной онтологии: определение, синонимы, комментарий и ссылки на PubMed.

В центральной части карточки представлена иерархия термина:
над выбранным заболеванием (в данном примере - "Glioma") отображаются его родительские термины -
те фенотипические группы, в состав которых оно входит. Ниже отображаются дочерние
термины - заболевания и фенотипы, входящие в группу "Glioma".

В правой части карточки приведён список генов, ассоциированных с данным фенотипом или заболеванием.

Над карточкой фенотипа отображаются термины, выбранные для фильтрации, с указанием идентификатора из онтологии.
В скобках указано количество генов, ассоциированных с каждым термином. Чтобы открыть карточку фенотипа,
нажмите на него. Чтобы удалить термин из фильтрации, нажмите на
крестик <img src={require('/img/vv/delete_term_btn.png').default} width="15"/>:

<p align="center">
<img src={require('/img/vv/delete_term.png').default} width="700"/>
</p>

- **Поиск по иерархии терминов.** В карточке фенотипа доступна навигация по иерархии терминов. Нажмите на
название родительского или дочернего фенотипа, чтобы перейти к его карточке.<br></br>
Если термин ещё не выбран для фильтрации и для него найдены связанные гены,
нажмите кнопку <img src={require('/img/vv/add_term.png').default} width="150"/>, чтобы включить его в фильтр
вариантов.

- **Поиск в режиме мультиселекта.** Для этого нажмите на правую кнопку переключателя режима поиска
в левом верхнем углу окна: <img src={require('/img/vv/switch_mode.png').default} width="120"/>.
Вы увидите список основных фенотипических групп с флажками для выбора.

<p align="center">
<img src={require('/img/vv/multiselect_mode_hpo.png').default} width="800"/>
</p>

Поиск осуществляется:
- по названию (полному или частичному);
- по идентификатору HPO (например, "HP:0009733" или "0009733");
- по идентификатору Mondo (например, "MONDO:0009733" или "0009733").

Например, при поиске по запросу “glioma” отображаются несколько соответствующих терминов:

<p align="center">
<img src={require('/img/vv/multiselect_hpo.png').default} width="800"/>
</p>

В режиме мультиселекта можно выбрать сразу несколько терминов в выпадающем списке.
Для выбора фенотипа для фильтрации активируйте соответствующий флажок.

<p align="center">
<img src={require('/img/vv/glioma_checked.png').default} width="400"/>
</p>

Чтобы закончить добавление фенотипов, кликните вне области выпадающего списка в
пределах формы поиска. Наверху формы вы увидите термины, выбранные для фильтрации. В скобках
указано количество связанных с фенотипом генов. Нажав на фенотип, вы увидите его карточку.
Фенотип можно удалить, нажав на крестик <img src={require('/img/vv/delete_term_btn.png').default} width="15"/>.

<p align="center">
<img src={require('/img/vv/multiselect_mode.png').default} width="800"/>
</p>

Чтобы ***отфильтровать варианты*** по генам, связанным с выбранными фенотипами,
нажмите <img src={require('/img/custom-annot/ok_btn.png').default} width="130"/>.
Список выбранных терминов можно увидеть во всплывающей подсказке, наведя курсор на поле фильтрации по онтологии:

<p align="center">
<img src={require('/img/vv/chosen_phenotypes.png').default} width="400"/>
</p>

Чтобы ***отменить фильтрацию*** по всем терминам, наведите курсор на поле фильтрации по онтологии и
нажмите на появившийся крестик:

<p align="center">
<img src={require('/img/vv/cancel_hpo.png').default} width="150"/>
</p>

или нажмите на поле и отредактируйте выбор в форме поиска фенотипов.

### 5. Шкала фильтрации по глубине секвенирования {#depth-scale}

Фильтрация по минимальному
уровеню глубины. Можно варьировать уровень как с помощью плюса-минуса, так и с помощью слайдера.
Между 1x и 50x шаг фильтрации (цена деления) - 1, между 50x и 100x - 3, а между 100x и 300x - 7.

<p align="center">
<img src={require('/img/vv/seq_depth.png').default} width="350"/>
</p>

### 6. Ваши запросы {#saved-queries}

Фильтрация по сохранённым запросам. Осуществляется в двух режимах:
- Один запрос. При выборе одного запроса после применения фильтра над таблицей отображаются все условия,
входящие в данный запрос.
- Несколько запросов. При одновременном выборе нескольких запросов фильтрация выполняется как
объединение запросов по логическому оператору ИЛИ. В этом случае над таблицей отображаются только
названия выбранных запросов, а входящие в них условия можно посмотреть в конструкторе запросов.

Сохранение запросов
описано в <a href="/results/main/snvs-indels/advanced-filtering#save-query">соответствующем разделе</a>.

## Сброс фильтрации {#reset-filtering}

Для сброса ***всех*** примененных фильтров
нажмите на <img src={require('/img/vv/clear_filters.png').default} width="43"/>.

Для сброса ***отдельного фильтра***:
- Нажмите на поле фильтрации и затем на <img src={require('/img/vv/clear_option.png').default} width="100"/>.
- Если фильтр позволяет выбрать сразу несколько опций (например, фильтр по гену), то можно убрать одну из
выбранных опций фильтрации. Для этого нажмите на поле фильтрации и снимите галочку у опции.
- Чтобы изменить выбранные фенотипы, по которым выполняется фильтрация вариантов, нажмите на поле фильтрации
по онтологии и отредактируйте выбор в форме поиска фенотипов.
Чтобы сбросить фильтрацию по всем выбранным терминам, наведите курсор на поле фильтрации по онтологии и
нажмите на появившийся крестик:

<p align="center">
<img src={require('/img/vv/cancel_hpo.png').default} width="150"/>
</p>
