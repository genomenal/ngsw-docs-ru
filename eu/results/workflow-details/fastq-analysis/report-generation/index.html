Генерация отчётов

Для образца запускается генерация отчётов, если выполняются следующие условия:

  1. В системе есть хотя бы один активный шаблон отчёта, у которого есть хотя бы один добавленный блок и который применим к типу образца. Шаблон может быть применим к опухолевым, неопухолевым образцам и образцам любого типа. Кроме того, шаблон отчёта, подходящий под все перечисленные условия, должен быть добавлен в систему раньше, чем был обработан образец. Если вы добавили или обновили шаблон отчёта позже и хотите построить или обновить соответствующий отчёт для данного образца, то перезапустите анализ образца с задачи "Генерация отчётов".
  2. В анализ образца включены выравнивание и одна из следующих стадий анализа: "Выявление соматических SNVs/Indels" для опухолевого образца; "Выявление герминальных SNVs/Indels" для неопухолевого или одиночного опухолевого образца или "Выявление вариации числа копий". Наличие остальных стадий анализа может повлиять только на построение конкретных отчётов или их наполнение.
  3. Анализ образца успешно завершился (то есть все стадии, включённые в анализ, имеют статус "Завершено").

В ходе задачи генерации отчётов система рассматривает все шаблоны, подходящие под перечисленные выше условия, и строит отчёты по этим шаблонам, если для них выполняется хотя бы одно из следующих условий:

  • Если в анализ образца включена стадия выявления соматических и/или герминальных SNVs/Indels, то для построения отчёта его шаблон должен включать хотя бы один блок с SNVs/Indels, совпадающими по типу мутации с SNVs/Indels, выявленными в образце. Так, если для образца были получены соматические SNVs/Indels, то ему подойдут блоки с соматическими SNVs/Indels. А если для образца были получены герминальные SNVs/Indels, то ему подойдут блоки с герминальными SNVs/Indels.
  • Если в анализ образца включена стадия выявления структурных вариаций, то для построения отчёта его шаблон должен включать хотя бы один блок со структурными вариациями (при этом обязательно включение в анализ образца хотя бы одной из стадий выявления SNVs/Indels или вариации числа копий).
  • Если в анализ образца включена стадия выявления вариации числа копий, то для построения отчёта его шаблон должен включать хотя бы один блок с вариациями числа копий.
  • Отчёт, шаблон которого включает блок с полигенными признаками, будет построен для образца, если выполняются следующие условия:
    1. В анализ образцов включено вычисление полигенных рисков (параметр "Run polygenic risk scores calculation").
    2. В анализ образца включена хотя бы одна из стадий выявления SNVs/Indels или вариации числа копий.
    3. Если в анализ включены фильтрация по качеству и импутация, то обязательно успешное прохождение образцом проверки контроля качества.
  • Шаблон отчёта включает только блоки, не зависящие от стадий анализа. Это такие блоки, как "Раздел", "Информация о пациенте", "Информация об образце", "Информация о контрольном (неопухолевом) образце" (если образцы были загружены в виде пары образцов опухоль/контроль), "Форматированный текст", "Дисклеймер", "Место для подписи", "Клинические испытания", "Глиома: список литературы".

Стадией "Генерация отчётов" анализ образца завершается.
