Генерация отчётов

Для образца запускается генерация отчётов, если выполняются следующие условия:

  1. В системе есть хотя бы один активный шаблон отчёта, у которого есть хотя бы один добавленный блок и который применим к типу образца. Шаблон может быть применим к опухолевым, неопухолевым образцам и образцам любого типа. Кроме того, шаблон отчёта, подходящий под все перечисленные условия, должен быть добавлен в систему раньше, чем был обработан образец. Если вы добавили или обновили шаблон отчёта позже и хотите построить или обновить соответствующий отчёт для данного образца, то перезапустите анализ образца с задачи "Генерация отчётов".
  2. Анализ образца успешно завершился (то есть все стадии, включённые в анализ, имеют статус "Завершено").
  3. В загруженной аннотации есть SNVs/Indels.

В ходе задачи генерации отчётов система рассматривает все шаблоны, подходящие под перечисленные выше условия, и строит отчёты по этим шаблонам, если для них выполняется хотя бы одно из следующих условий:

  • Шаблон отчёта включает хотя бы один блок с SNVs/Indels, совпадающими по типу мутации с SNVs/Indels в образце. Так, для образца опухолевой ткани будут получены соматические SNVs/Indels, и ему подойдут блоки с соматическими SNVs/Indels. А образцу неопухолевой ткани будут подходить блоки с герминальными SNVs/Indels.
  • Шаблон отчёта включает блок с полигенными признаками. Отчёты по таким шаблонам строятся только для образцов, для которых выполняются следующие условия:
    1. В анализ образцов включено вычисление полигенных рисков (параметр "Run polygenic risk scores calculation").
    2. Если в анализ включены фильтрация по качеству и импутация, то обязательно успешное прохождение образцом проверки контроля качества.
  • Шаблон отчёта включает только блоки, не зависящие от стадий анализа. Это такие блоки, как "Раздел", "Информация о пациенте", "Информация об образце", "Информация о контрольном (неопухолевом) образце" (если образцы были загружены в виде пары образцов опухоль/контроль), "Форматированный текст", "Дисклеймер", "Место для подписи", "Клинические испытания", "Глиома: список литературы".

Стадией "Генерация отчётов" анализ образца завершается.
