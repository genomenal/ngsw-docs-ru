Основные шаблоны отчётов

В данном разделе описаны основные шаблоны отчётов, которые используются для представления результатов анализа. Некоторые из них могли быть добавлены в ваш профиль администратором при регистрации в Системе. Если вам понадобятся другие шаблоны отчётов, описанные здесь, вы можете обратиться к администратору или добавить их самостоятельно, как описано ниже.

1. Отчёт для анализа глиомы#

  • клинический отчёт о характеристиках глиом, основанный на онко-маркерах, выявленных в образце, и базе знаний, созданной на основе эскпертных знаний и научных публикаций по данной тематике;
  • влияет на построение отчёта для анализа глиомы;
  • подходит для представления результатов анализа образцов глиомы в любом формате файлов.

Условия построения отчёта#

Отчёт для анализа глиомы строится для образца, если выполняются следующие условия:

  1. Образец загружен как образец опухолевой ткани.
  2. Анализ образца успешно завершился (то есть все стадии анализа имеют статус "Завершено").
  3. Для одиночного образца опухоли (tumor-only) успешно завершилась хотя бы одна из следующих стадий: "Аннотация соматических SNVs/Indels", "Аннотация герминальных SNVs/Indels" или "Выявление вариации числа копий". Если же у вас набор образцов "опухолевый + соответствующий ему неопухолевый образец" (tumor-normal), то для построения отчёта необходимо, чтобы для опухолевого образца успешно завершилась стадия "Аннотация соматических SNVs/Indels" или "Выявление вариации числа копий" или для неопухолевого - "Аннотация герминальных SNVs/Indels" или "Выявление вариации числа копий".
  4. Шаблон отчёта активен.
  5. Шаблон отчёта был добавлен раньше, чем был обработан образец.

2. Отчёт по CNV#

  • отчёт по результатам анализа числа копий хромосом в исследованном образце или образцах пациента;
  • влияет на построение отчёта по CNV для образца и отчёта по CNV для пациента (для всех образцов пациента);
  • подходит для представления результатов анализа неопухолевых образцов в формате FASTQ или BAM.

Условия построения отчёта#

Отчёт по CNV строится для образца, если выполняются следующие условия:

  1. Образец загружен как образец неопухолевой ткани.
  2. Анализ образца успешно завершился (то есть все стадии анализа имеют статус "Завершено"). Если анализ завершился с ошибкой, то в "Отчёте по CNV" для пациента будет соответствующее сообщение для образца, а "Отчёт по CNV" для образца не построится.
  3. Для образца успешно завершилась стадия "Выявление вариации числа копий". Если стадия завершилась с ошибкой, то в "Отчёте по CNV" для пациента будет соответствующее сообщение для образца, а "Отчёт по CNV" для образца не построится. Если стадия исключена из анализа, то отчёт для образца не построится, а в отчёте для пациента образец упомянут не будет. Если стадия выключена у всех образцов пациента, то "Отчёт по CNV" для пациента не построится.
  4. Шаблон отчёта активен.
  5. Шаблон отчёта был добавлен раньше, чем был обработан образец.
